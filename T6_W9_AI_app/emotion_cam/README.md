# emotion_cam

Phone camera demo that draws face bounding boxes and shows an emotion label.

This app is fully offline and uses on-device ML Kit face detection + classification
to produce a simple emotion signal ("happy" vs "neutral") based on smile probability.

## Getting Started

### Run the Flutter app

From `emotion_cam/`:

- `flutter pub get`
- `flutter run`
